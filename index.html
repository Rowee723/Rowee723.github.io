What I built on Blockstone Island

  1. 01

    Star Board leaderboard

    Star Board is Blockstone Island’s leaderboard. I was its primary author and built it in about 3 weeks.

    What I built

    • A client-side leaderboard service that calls the game’s API, with server-driven config and dynamic reward tiers.
    • World and Country tabs with rank-change indicators, avatar sync and HUD floating text.
    • Results screen, FTUE, offline handling and pitched SFX.
    • Leaderboard analytics events and debug tooling.
    • Unity 6
    • C#
    • REST/JSON
    • Server-driven config
    • Amplitude

  2. 02

    Spark Fever live event

    Spark Fever is one of Blockstone Island’s rotating live events. I implemented it on a teammate’s framework, then became the top contributor to the live-event code.

    What I built

    • Reward ladder, FTUE, progress bar and banking, plus fly and event-switch animations.
    • Island Treasure fixes and an optimisation pass over the live-event scripts and assets.
    • Rotation and duration validation, covered by 31 rotation and schedule tests.
    • The 10-minute poller behind remote-config and live-event refresh.
    • Unity 6
    • C#
    • Remote config (JSON)
    • ScriptableObjects
    • Unity Test Framework

  3. 03

    Player gifting with crash-safe claims

    I built the client side of player gifting, from the HUD button to the reward reveal. Claims are crash-safe: rewards are saved before the claim request goes out.

    What I built

    • Rewards are saved before the claim request, because the server doesn’t resend them when a claim is repeated.
    • A three-beat bottle popup, reward reveal, HUD button and expiry timers.
    • Failed-claim recovery, with its own panel.
    • Five funnel analytics events and 68 EditMode and PlayMode tests.
    • Checked the backend contract and wrote a spec for a follow-up endpoint change.
    • C#
    • REST/JSON
    • JSON saves
    • Amplitude
    • Unity Test Framework

  4. 04

    Ads and monetisation

    I co-built Blockstone Island’s AppLovin MAX ad layer and wrote its first IAP manager. For banners, I built a layout solver that shrinks the puzzle board and deck to make room.

    What I built

    • A rewarded continue on the fail flow, run as an Amplitude A/B flag with a remote kill switch.
    • A Daily Rewards ad variant, driven by remote config with a ScriptableObject fallback.
    • App-resume interstitials with a countdown popup.
    • Adaptive banners with a layout solver that resizes the board and deck, covered by 33 EditMode tests.
    • The first IAP manager, since taken over by teammates, and an economy upgrade with transaction records.
    • AppLovin MAX
    • Amplitude A/B flags
    • Remote config
    • VoxelBusters Essential Kit
    • Unity Test Framework

Fill This Hole

Casual 3D hole-puzzle game · live since Feb 2026 · 10K+ downloads · 4.5★ stars from 198 reviews (Oct 2026)

What I built

  • Contest lifecycle, a durable score-submission queue, World/Country boards and the claim flow, hardened through code review and QA.
  • Wrote 8 backend API specs, including the leaderboard contract the client integrates against.
  • Extracted the leaderboard into a UPM package designed for reuse: nine provider interfaces, no game dependencies. Not yet integrated.
  • Created the Treasure Pass controllers and built the season pass with a co-developer, later moving it onto backend data.
  • Created Goldie’s Pack, a tiered IAP offer with a carousel and eligibility window, later extended by a teammate.
